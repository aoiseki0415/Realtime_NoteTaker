# Realtime NoteTaker

Mac Air上で使う、個人用のリアルタイム議事録アプリです。会議・動画の音声を文字起こしし、会議中はローカルで議事録を更新、終了後にMarkdownとしてこのGitHubリポジトリへ保存します。

## 目的

- 会議中に、重要発話の時系列ログと構造化した議事録を生成する。
- 対面会議、オンライン会議、動画視聴を一つのアプリで扱う。
- マイク音声とシステム音声を分離し、可能な範囲で話者を区別する。
- 原音声は保存せず、外部送信・保存する内容を最小限にする。

## 想定する利用場面

| 場面 | 取得する音声 | 話者の扱い |
| --- | --- | --- |
| 対面会議 | マイク | 自分を含む参加者を話者分離する。 |
| オンライン会議 | マイク + 選択した会議アプリのシステム音声 | マイクは`自分`、システム音声は相手側として話者分離する。 |
| 動画視聴 | 選択したアプリのシステム音声 | 話者数1を初期値として扱う。 |

オンライン会議では、Zoom、Microsoft Teams、Google Meet、その他を選択できます。Google Meetはブラウザ上で動くため、実際に使用するChrome、Safari、Edgeなどを音声取得対象として選びます。

## 使い方の流れ

1. 会議名、利用場面、想定参加者数、音声機器、オンライン会議アプリ、議事録テンプレートを設定する。
2. 録音・文字起こし、およびOpenAI APIへの送信について同意確認を行う。
3. 音声取得を開始する。
4. 文字起こしは継続的に行い、30秒ごとに議事録を更新する。
5. 会議終了時にMarkdown議事録を生成し、このリポジトリへ自動コミット・プッシュする。
6. 一時的な全転写を削除するか確認する。

## 議事録の構成

1つの議事録はMarkdownファイルとして保存します。

```text
議事録管理/YYYY/MM/YYYY-MM-DD_HHMM_会議名.md
```

ファイルの上部には内容を整理した要約、下部には重要発話だけを時系列で記録します。

```text
構造化したまとめ
  - 決定事項、ToDo、未解決事項など

重要発話ログ
  - 時刻、話者ラベル、発話本文
```

初期テンプレートは「標準会議」「研究・プロジェクト進捗」「動画視聴・講義メモ」です。
