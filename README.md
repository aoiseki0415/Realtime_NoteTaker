# Realtime NoteTaker

Mac Air上で使う、個人用のリアルタイム議事録アプリです。会議・動画の音声を文字起こしし、会議中はローカルで議事録を更新、終了後にMarkdownとしてこのGitHubリポジトリへ保存します。

## 目的

- 会議中に、重要発話の時系列ログと構造化した議事録を生成する。
- 対面会議、オンライン会議、動画視聴を一つのアプリで扱う。
- マイク音声とシステム音声を分離し、可能な範囲で話者を区別する。
- 原音声は保存せず、外部送信・保存する内容を最小限にする。

## 想定する利用場面

| 場面 | 取得する音声 | 話者の扱い |
| --- | --- | --- |
| 対面会議 | マイク | 自分を含む参加者を話者分離する。 |
| オンライン会議 | マイク + 選択した会議アプリのシステム音声 | マイクは`自分`、システム音声は相手側として話者分離する。 |
| 動画視聴 | 選択したアプリのシステム音声 | 話者数1を初期値として扱う。 |

オンライン会議・動画視聴では、Zoom、Microsoft Teams、Google Chromeを音声取得対象として選択できます。Google MeetはGoogle Chrome上で利用するため、`Google Chrome`を選びます。

## 起動と更新

- 普段使う実行用アプリは、`~/Applications/RealtimeNoteTaker.app` に配置する。Finderからダブルクリックして起動でき、Dockへ追加すれば次回以降はDockから起動できる。
- このリポジトリ（`~/GitHub/Realtime_NoteTaker`）はソースコード・設定・議事録の保存先である。修正は必ずこちらで行い、`~/Applications/RealtimeNoteTaker.app` の中身を直接編集しない。
- 修正後は、リポジトリでビルドした最新版を実行用アプリへ反映する。アプリ本体を更新した後、macOSから画面収録・システムオーディオ録音の許可を付け直す必要がある場合がある。
- マイク入力とスピーカー出力はアプリ内で`MacBook Air（内蔵）`または`イヤホン`を選ぶ。実際に使う機器は、会議前にMacのコントロールセンターでも入力・出力デバイスとして選択する。

## 使い方の流れ

1. 会議名、利用場面、想定参加者数、音声機器、オンライン会議アプリ、議事録テンプレートを設定する。
2. 録音・文字起こし、およびOpenAI APIへの送信について同意確認を行う。
3. 音声取得を開始する。
4. 文字起こしは継続的に行い、30秒ごとに議事録を更新する。
5. 会議終了時にMarkdown議事録を生成し、このリポジトリへ自動コミット・プッシュする。
6. 一時的な全転写を削除するか確認する。

OpenAI APIの利用額・クレジット残高は、開始前または終了後に [Usage](https://platform.openai.com/usage) で確認する。

## 議事録の構成

1つの議事録はMarkdownファイルとして保存します。

```text
議事録管理/YYYY/MM/YYYY-MM-DD_HHMM_会議名.md
```

ファイルの上部には内容を整理した要約、下部には重要発話だけを時系列で記録します。

```text
構造化したまとめ
  - 決定事項、ToDo、未解決事項など

重要発話ログ
  - 時刻、話者ラベル、発話本文
```

初期テンプレートは「研究・プロジェクト進捗」「GD用」「動画視聴・講義メモ」です。
